2. Typography

Typeface Pairing

Libre Franklin for Headings
--font-heading · Libre Franklin, system sans-serif stack
Libre Baskerville for body text. Its generous x-height and sturdy serifs provide excellent screen readability while preserving the gravitas appropriate to legal and academic contexts. The pairing of a transitional serif with a geometric sans creates a scholarly-but-modern impression.
--font-body · Libre Baskerville, serif fallback stack
const tokens = require('./tokens.css'); // SF Mono, Cascadia Code, Fira Code
--font-mono · system monospace stack
